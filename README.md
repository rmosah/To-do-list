# Daily Task Manager

## What is this project?
A web app for managing daily tasks with an Arabic interface built using HTML, CSS, and JavaScript. It creates each task as an object with a timestamp ID and completion status, saving the list in `localStorage` across reloads.

### Features
* Toggle task completion, delete individual tasks, or clear all completed tasks at once.
* Filter displayed tasks by **All**, **Active**, or **Completed**.
* Automatically update the remaining task counter.

## How to use it
1. Download or clone the project repository to your device.
2. Open the `index.html` file in any web browser.
3. Add your daily tasks, mark them as completed, filter them, or clear completed tasks.
